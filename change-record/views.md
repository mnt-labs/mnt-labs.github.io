# Saved and shared views

A view is a filter, a sort and a date window with a name. Views live in the
toolbar.

**Save a view.** Set the filter, open *Views*, give it a name (for example
"Payments without status changes") and save. A view stores the preset, not
the dates it resolved to, so "Last 30 days" stays relative.

**Share a view with the site.** Mark a saved view as shared. Anyone on the
site can then open it from the same Views menu and export it. Only you can
change, schedule or delete it. Every person who opens it still sees only
the projects they can browse; sharing a view never widens anyone's access.

**Copy a link.** *Share* in the toolbar copies a Jira URL. Two kinds:

- a **filter link** carries the current filter, view settings and sort;
- a **view link** opens a named saved view.

The link is a normal Jira page URL, so Jira's login gates it and the
viewer's own project access scopes what it shows. Paste it in a work item,
a Confluence page or a chat.

**What a shared view is not.** It is not a permission. It does not grant
access to a project, and it is not a report template: the columns are
fixed.
