# Change History for Jira — Filter, Report & Export

Documentation for the app. Each page answers one question in under a minute.
These pages are the documentation link on the Marketplace listing.

1. [Install](install.md) — where the app appears, what it records, what the free tier includes.
2. [First open and the consent prompt](first-open.md) — the one prompt you see once, and why.
3. [Filters and exclusions](filters.md) — include or exclude any project, field or person; the date window.
4. [Transitions](transitions.md) — find every change from one value to another.
5. [Saved and shared views](views.md) — save a filter, share it with the site, copy a link.
6. [Scheduling](scheduling.md) — a saved view delivered daily or weekly.
7. [Export and the settings sheet](export.md) — CSV and XLSX, the row cap, what the second sheet says.
8. [The file digest](digest.md) — check a downloaded file against the SHA-256 the app printed.
9. [Retention](retention.md) — how long records are kept, and who can change it.
10. [The verification report](verification.md) — what "chain intact" means, and what a break would mean.
11. [Configuration changes](configuration.md) — the optional record of workflow, scheme, field and permission changes.
12. [What is deliberately not built](not-built.md) — read this before asking for a feature.

Every number in these pages is either read from Atlassian's documentation
or measured on our own sites; the app's `docs/LIMITS.md` holds the source
and the date for each.
