# MNT Labs — brand assets

Built 2026-09-19 from the brand board (Thomas, ChatGPT render). The wordmark
is drawn as vector paths, so it needs no font; "LABS" and the tagline are
set in Inter (open licence), with Söhne as the board's primary if it is ever
bought.

## Geometry

Cap height 100, stroke 24. M and N share a stem (the N's diagonal starts at
the top of the M's right stem); the T stands apart with a 16-unit gap. Tops
and baselines are flat: the miters are clipped to the cap box. Total mark
box 304 × 100. Minimum size: 80 px wide for the mark, 120 px for the
wordmark with LABS.

## Rules

This is the company identity: partner profile, docs hub, email signature,
invoices. **It never goes on an app.** Each app carries its own icon and
copy in the marketplace's visual language (`mapl/CLAUDE.md`, "Brand fits
the app, not the company").
